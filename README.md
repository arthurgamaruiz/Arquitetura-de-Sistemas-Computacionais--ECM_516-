## ◈ Sobre

Este repositório documenta minha jornada pela disciplina **ECM516**, cobrindo desde os fundamentos de arquitetura de software até a implementação de sistemas distribuídos em escala de produção.

A disciplina parte de princípios teóricos sólidos e evolui até práticas modernas de engenharia — APIs RESTful, microsserviços, orquestração de contêineres e arquiteturas para Big Data.
